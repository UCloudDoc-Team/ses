# 如何查看你的邮件统计数据？

在成功发送邮件之后，跟踪并分析数据是对于邮件营销活动的成功而言至关重要的一步。无论你是想查看具体的发信记录和收信回执，还是衡量用户互动表现，**uSpeedo** 都提供了一套全面的分析能力，帮助你清晰了解邮件离开平台之后究竟发生了什么。

借助这些洞察，你可以优化发送策略、提升发件人声誉，并为业务带来更好的结果。

## 关键指标（KPI）

在 <a href="https://console.uspeedo.com/email/analytics" target="_blank">**记录分析**</a> 中，我们会跟踪若干核心指标：

- **有效请求数**：平台接收到的邮件发送请求总数。
    
- **送达**：收件方邮件服务器成功接收的邮件数量。
    
- **打开**：打开过邮件的收件人数量（去重）。
    
- **点击**：点击过邮件内链接的收件人数量（去重）。
    
- **退信**：未能投递成功的邮件，通常是由于收件箱永久性问题或收件地址无效等原因导致。
    
- **拦截**：通常是由于域名声誉、安全策略或 ISP 限制而被拒收的邮件。
    
- **临时问题（软退信）**：由于临时性原因导致失败的邮件，例如限流或服务器侧拥塞。
  
  > _建议: 这些邮件通常可以在24-72小时后重新尝试发送。_
    
- **退订**：通过退订链接选择退出邮件订阅的收件人数量。
    
- **垃圾举报**：手动将邮件标记为“垃圾邮件”的收件人数量。

## 数据可视化

为了帮助你理解这些数字，uSpeedo 提供了多个交互式图表与板块：

### 1. 邮件转化漏斗

该自上而下的可视化会跟踪邮件从 **有效请求数** → **送达** → **打开** → **点击** 的路径数据。这是最快定位你可能在哪一步流失受众的方法。

### 2. 送达趋势

一张全面的时间序列图，便于你按天、按周或按月监控表现波动。你可以用它追踪日常投递情况或识别投递突然下滑或互动突然上升等情况。

### 3. 拦截失败分析

用于拆解邮件为何被拒收的专门板块。该部分会按类型对被 “拦截” 邮件的原因进行分类。

> **小建议:** 如需更深入查看错误码，请点击该板块右上角的 **失败分析**。

### 4. 每日汇总

按日期组织的数据表格视图，适合审计每日表现，并可 **导出** 以满足内部报表需求。

## 操作步骤

### 如何筛选并查看特定数据

1. 进入 <a href="https://console.uspeedo.com/email/analytics" target="_blank">**记录分析**</a> 页面。
    
2. 使用页面顶部的筛选项缩小查看范围：
    
    1. **时间范围**：选择你要分析的具体日期区间。
        
    2. **邮件类型**：在 **事务性邮件**（例如验证码、订单通知等）与 **营销邮件** 之间切换。
        
    3. **发信域名**：按特定域名筛选，以对比业务不同部分的表现差异。

### 排查单封邮件日志与失败原因

如果你发现 退信 或 拦截 比例较高，可以进一步定位根因：

1. 进入 <a href="https://console.uspeedo.com/email/analytics?type=record" target="_blank">**发送记录**</a> 页面。
    
2. 找到你要查看的具体记录。
    
3. 点击记录左侧的 **箭头图标** 展开详情。
    
4. 查看 **描述**，以获取收件方邮件服务器返回的具体原因。
    
<img src="https://cdn.uspeedo.com/docs_external/receipt-description.png" alt="邮件发送记录的原因回执" />


### 深入分析互动情况

如果你想查看是谁在与你的内容互动：

1. 进入 <a href="https://console.uspeedo.com/email/analytics?type=engagement" target="_blank">**互动记录**</a> 页面。
    
2. 在这里你可以查看 **打开、点击、退订** 与 **垃圾举报** 的具体日志，包括收件人地址与时间戳。

## 高级分析：失败分析

当你需要的是进阶的智能原因分析时，我们的 <a href="https://console.uspeedo.com/email/analytics?type=failureAnalysis" target="_blank">**失败分析**</a> 工具可以提供更智能的诊断能力：

- **AI诊断洞察**：点击 **进行深度分析** 按钮，让 uSpeedo 的 AI 引擎对失败原因进行分类，并给出可执行的修复建议。
    
- **明细拆解**：查看失败原因的排名列表，从而优先处理影响用户最多的问题（例如解除某个 ISP 的拦截）。
