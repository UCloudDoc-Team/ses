# 配置邮件发送速率

邮件发送速率（或称速率限制）是维护健康发件人信誉的关键工具。通过控制特定时间段内的邮件发送量，您可以有效地对域名进行**预热**，避免被互联网服务提供商（ISP）标记为垃圾邮件。

对于新域名或近期活跃度较低的域名，逐步增加发送量有助于建立信任，并确保您的活动获得更高的送达率。

## 核心优势
- **域名预热**：逐步与 Gmail、Outlook 等 ISP 建立信誉。
- **提升送达率**：降低邮件被限流或拦截的风险。
- **流量管理**：在大规模发送时更好地控制服务器资源使用。

## 如何配置发送速率
您可以在 uSpeedo 控制台中为任意**已认证域名**管理发送速率。按以下步骤开始配置：

1. **进入设置页面**：登录您的 uSpeedo 账号，进入 <a href="https://console.uspeedo.com/email/setting?type=domain" target="_blank">设置 > 域名与发件人</a>。
2. **找到目标域名**：在活跃域名列表中找到您要配置的域名。
   - 注意：只有状态为「已认证」的域名支持速率配置。
3. **打开发送速率设置**：点击对应域名行右侧的**发送速率**按钮。
4. **设置限制值**：在配置窗口中开启功能，并输入您期望的发送频率。
   - **当前限制**：uSpeedo 支持范围为**每分钟 1–60 封邮件**。
5. **保存修改**：确认设置，新速率将立即生效。

## 小贴士与最佳实践
**起点要低，稳步提升**：

如果您使用全新域名，建议从低速开始（例如每分钟 1–5 封），并在数周内根据互动指标保持良好的情况下逐步提升。

**监控退信情况**：

如果您发现特定服务商的「软退信」或「限流」错误增加，可考虑暂时降低发送速率。

**认证为前提**：

如果未看到「发送速率」按钮，请检查您的域名 DNS 记录是否已在 uSpeedo 平台完成完整认证。

## 常见问题
**是否可以为不同域名设置不同速率？**

可以。发送速率按单个域名独立配置，允许您在对新域名进行预热的同时，在成熟域名上保持高量发送。

**如果活动超出设置速率会怎样？**

uSpeedo 会自动将邮件排队，并按照您配置的限制逐步释放。您无需手动暂停活动，系统会自动控制发送节奏。

**是否可以将速率提高到每分钟 60 封以上？**

目前支持的最高速率为每分钟 60 封。如有更高发送量需求或专属 IP 咨询，请联系我们的支持团队。
