# 域名信誉系统

uSpeedo 上的每个发件域名都有独立的**信誉等级**（1–20），决定该域名每日可发送的邮件数量上限。等级越高，每日额度越大。系统会根据您的发送质量指标自动调整等级——发送质量优秀的域名将自动升级，质量不佳则会触发降级。

---

## 如何查看域名信誉

进入 **邮件控制台 → [设置](https://console.uspeedo.com/email/setting)**，可以管理账户下的所有发件域名。每个域名旁边均会直接显示当前信誉等级和当日额度使用情况，方便您随时跟踪进度、及时发现问题。

---

## 为什么需要信誉系统？

邮件送达能力是一种共享资源。某个域名的信誉变差，可能波及 uSpeedo 所有客户共用的 IP 池和基础设施。信誉系统通过以下方式保障整体质量：

- **奖励优质发送者**，自动提升配额上限
- **隔离低质量发送**，避免影响共享基础设施
- **让您清晰了解**域名状态及背后原因

---

## 新域名初始等级

| 情况 | 初始等级 |
|------|---------|
| 新域名（DNS 未验证） | 无法发送 |
| 新域名（DNS 已验证） | 第 2 级 |
| 新域名，且账户内已有第 10 级及以上域名，且过去 30 天内无降级记录 | 最高第 5 级（自动） |

## 升级规则

当天发送结束后，若**同时满足**以下所有条件，系统将自动触发升级。

### 事务型域名

| 指标 | 阈值 |
|------|------|
| 当日发送量 | ≥ 300 封 |
| 额度使用率（发送量 ÷ 每日额度） | ≥ 70% |
| 送达率 | ≥ 92% |
| 退信率 | ≤ 3% |
| 垃圾邮件投诉率 | ≤ 0.15% |
| 打开率 | ≥ 15% |

### 营销域名

| 指标 | 阈值 |
|------|------|
| 当日发送量 | ≥ 300 封 |
| 额度使用率（发送量 ÷ 每日额度） | ≥ 70% |
| 送达率 | ≥ 90% |
| 退信率 | ≤ 5% |
| 垃圾邮件投诉率 | < 0.20% |

> **所有条件必须同时满足。** 满足四项但遗漏一项也不算达标——同一天内每项阈值均需通过。

### 升级建议

- **充分利用每日额度。** 额度使用率 ≥ 70% 是硬性要求。如果您的第 5 级域名每日额度为 10,000 封，而实际只发了 3,000 封，即便其他指标全部达标，也不会触发升级。
- **定期清理列表。** 向失效或无效地址发送邮件会拉高退信率。在大规模营销前，建议先使用[邮箱校验服务](https://uspeedo.com/docs/zh-Hans/products/email/campaigns/deliverability/email-validation/how-to-use-email-validation)或[邮箱校验API](https://uspeedo.com/docs/zh-Hans/products/email/api/BatchVerifyEmail)进行列表清洗。
- **提供便捷的退订入口。** 清晰可见的退订链接可以降低垃圾邮件投诉率，这是影响升级资格最关键的指标之一。
- **逐步增量发送。** 如果您近期大幅提升了发送量，收件箱服务商在重新评估您的信誉期间，送达率和打开率可能会暂时下降。稳步增长优于突然飙升。

---

## 降级规则

当**任意一项**以下条件触发时，系统会立即执行降级。

### 事务型域名

| 条件 | 阈值 |
|------|------|
| 当日发送量 > 300 且退信率 | ≥ 5% |
| 当日发送量 > 300 且送达率 | ≤ 75% |
| 当日发送量 > 300 且垃圾邮件投诉率 | > 0.15% |
| 当日发送量 > 300 且封锁率 | ≥ 6% |
| 当日发送量 > 300 且临时失败率 | ≥ 10% |

### 营销域名

| 条件 | 阈值 |
|------|------|
| 当日发送量 > 300 且退信率 | ≥ 8% |
| 当日发送量 > 300 且送达率 | ≤ 70% |
| 当日发送量 > 300 且垃圾邮件投诉率 | ≥ 0.2% |

### 降级幅度

每次降级事件将等级**精确降低 1 级**。例如，第 6 级域名触发降级规则后变为第 5 级。

> **第 1 级特殊处理：** 若第 1 级域名触发降级规则，系统将启动人工审核流程，审核期间（最长 3 个工作日）发送功能暂停。如需申请提前审核，请联系 [support@mail-uspeedo.com](mailto:support@mail-uspeedo.com)。

### 降级后如何恢复

如果您在次日满足所有升级条件，域名可以立即自动升级。降级与升级之间没有冷却期——系统每天独立评估当天的指标数据。

降级后请重点排查以下方面：

1. **确认触发指标。** 降级通知邮件会明确告知是哪项指标超出了阈值，以及具体数值。
2. **审查收件人列表。** 移除无效地址、职能邮箱或已退订地址。必要时可使用邮箱校验服务在下次发送前清洗列表。
3. **检查邮件内容。** 垃圾邮件过滤器对误导性主题行、过高的图文比例、缺少物理地址或退订链接等问题较为敏感。
4. **审视发送模式。** 发送量突然激增是造成临时送达问题的常见原因，建议循序渐进地提升量级。

## 临时暂停

临时暂停比降级更为严重，会**立即生效**并阻断该域名的所有对外发送。

### 事务型域名——暂停触发条件

| 条件 | 阈值 |
|------|------|
| 当日发送量 > 300 且退信率 | ≥ 15% |
| 当日发送量 > 300 且垃圾邮件投诉率 | ≥ 0.3% |

### 营销域名——暂停触发条件

| 条件 | 阈值 |
|------|------|
| 当日发送量 > 300 且退信率 | ≥ 25% |
| 当日发送量 > 300 且垃圾邮件投诉率 | ≥ 0.3% |

### 暂停期间的影响

- 该域名的所有 API 发送请求将被拒绝。
- 暂停不会自动解除——您需要联系支持团队申请审核。
- 同账户下的其他发件域名**不受影响**。

### 解除暂停

1. 立即停止受影响域名的所有发送。
2. 审查并[清洗收件人列表](https://uspeedo.com/docs/zh-Hans/products/email/campaigns/deliverability/email-validation/how-to-use-email-validation)，移除所有可能导致高退信率或高投诉率的地址。
3. 检查邮件内容和发送规范。
4. 发送邮件至 [support@mail-uspeedo.com](mailto:support@mail-uspeedo.com)，主题行填写 `Domain Suspension Review Request — yourdomain.com`，邮件中请注明：
   - 域名名称
   - 问题原因说明
   - 已采取的改进措施

我们的团队通常在 3 个工作日内回复。

## 域名类型：事务型与营销性

域名类型决定适用哪套升级、降级和暂停阈值。事务型邮件（如收据、密码重置、通知）对相关性和收件人授权的要求更高，因此对应的标准相对更严格。

| 类型 | 典型使用场景 |
|------|------------|
| **事务型** | 订单确认、密码重置、账户提醒、双因素认证码 |
| **营销性** | 电子报、促销活动、重激活序列 |

域名类型在控制台添加域名时设置。如需修改，请联系支持团队。

---

## 域名独立性

账户下每个发件域名拥有独立的信誉等级、每日额度和历史指标记录。某个域名的降级不会影响其他域名，同样地，一个域名的优质信誉也无法转移给另一个域名。

## 常见问题

**Q: 为什么我发送量很少也会被降级？**

A: 降级规则仅在当日发送量超过 300 封时才会触发。发送量较少时不进行评估。如果您收到了降级通知，说明当天的发送量已超过该阈值。

**Q: 可以手动申请升级吗？**

A: 第 14 级及以下的升级完全自动化，无需手动申请。只要持续满足升级条件，系统会自动升级您的域名，无需任何操作。第 15 级及以上，请在控制台提交企业认证申请。

**Q: 我在自己的分析工具中看到的数据没问题，为什么 uSpeedo 显示的数值不一样？**

A: uSpeedo 的指标基于 SMTP 层反馈——包括送达确认、退信码以及收件箱服务商的反馈循环报告。第三方分析工具通常统计的是打开和点击行为，而非 SMTP 事件，因此两者数值会有差异。收件箱服务商评估您域名信誉所用的正是 SMTP 层数据，因此 uSpeedo 显示的数值对于送达能力判断更具参考价值。

**Q: 每日未使用的额度会累积吗？**

A: 不会。每日额度在 UTC+8 00:00 重置，从零开始计算，当天未使用的额度不会叠加到次日。

**Q: 我有多个域名，高信誉域名的额度可以共享给低等级域名吗？**

A: 不可以。额度和信誉均按域名独立管理，无法在域名之间共用或转移。

**Q: 降级后最快多久可以恢复？**

A: 次日即可。只要当天满足所有升级条件，就可以在次日自动升级，没有冷却期限制。
