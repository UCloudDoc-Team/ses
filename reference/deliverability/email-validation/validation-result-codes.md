# 校验结果代码

当您在 uSpeedo 中校验邮箱地址时，系统会执行一系列深度技术检测，以判断每个联系人的质量。本指南将说明每个结果字段的含义，帮助您判断哪些邮箱适合用于营销活动。

## 校验字段总览

| 字段名 | 说明 | 可能值 |
| --- | --- | --- |
| **Syntax** | 检查邮箱是否符合国际 RFC 格式标准。 | **Valid / Invalid** |
| **DNS** | 验证域名是否存在，且是否具备有效的邮件服务器（MX）记录。 | **Valid / Invalid** |
| **SMTP** | 测试该邮箱是否能够实际接收邮件请求。 | **Valid / Invalid** |
| **Disposable** | 识别该邮箱是否为临时性“一次性”地址。 | **True**（Disposable）/ **False**（Non-Disposable） |
| **Free Email** | 识别用户是否使用公共邮箱服务商（如 Gmail 或 Yahoo）。 | **True**（Free Email）/ **False**（Not Free Email） |
| **Gibberish** | 检测邮箱前缀是否为随机、机器人风格的字符串。 | **True**（Gibberish）/ **False**（Non-Gibberish） |
| **Catch-all** | 检测服务器是否会忽略邮箱前缀并接收所有邮件。 | **True**（Catch-all identified）/ **False** |
| **Spam** | 将该地址与全球实时黑名单进行比对。 | **True**（Yes, Spam）/ **False**（Non-Spam） |

## 字段详细说明
### 1. Syntax（语法校验）
在与任何服务器通信前，我们会先检查邮箱拼写与结构。这可确保地址没有缺少 `@` 符号、没有非法空格，并符合 **RFC 5322 标准**。

### 2. DNS Check（域名校验）
我们会验证域名（`@` 后面的部分）是否真实存在，以及是否已配置可收信的 MX 记录。

> **洞察**：如果 DNS 为 **Invalid**，可能意味着该公司已停业或域名已过期。请立即停止向这类地址发送邮件。

### 3. SMTP（邮件协议校验）
我们会探测收件服务器，并测试其收件人配置，判断该服务器是否愿意接收发往该用户的邮件。

> **洞察**：SMTP 返回 **Invalid** 基本等同于“硬退信”预警。继续发送会直接损害发件人信誉。

### 4. Disposable（一次性邮箱）
系统使用一个庞大且持续更新的全球数据库来识别“一次性”地址（例如 10 分钟邮箱）。

> **洞察**：用户常用此类邮箱来领取“免费试用”或优惠码，而无意阅读后续邮件。若为 **True**，互动率通常会下降。

### 5. Free Email（公共邮箱）
用于识别用户是否使用免费个人邮箱（Yahoo、Gmail、Outlook），而不是企业自定义域名邮箱。

> **策略**：如果您是 **B2B SaaS**，可以优先标记 **Free Email: True** 的地址，以便在销售触达中优先处理企业线索。

### 6. Gibberish（乱码/机器人邮箱检测）
我们使用高级算法检测该邮箱看起来是人工创建，还是随机脚本生成（例如 `ajksdhf982@domain.com`）。

> **洞察**：**True** 通常表示地址来自机器人，或用户在表单中随意“乱敲键盘”。这类地址触发垃圾投诉的风险较高。

### 7. Catch-all（全接收域名）
“Catch-all” 服务器会对任意前缀都返回可接收，即使该用户并不存在。

> **问题**：由于服务器对所有地址都回答“Yes”，我们无法 100% 确认该邮箱有效，因此 Catch-all 结果常被归类为 **Uncertain**。

### 8. Spam（黑名单校验）
我们会检查该地址或域名是否出现在全球反垃圾组织的黑名单中。

> **风险**：向 **Spam: True** 的地址发送邮件就像主动走进陷阱。这类地址常是服务商设置的“垃圾陷阱（Spam Traps）”，用于识别并拦截群发方。**请绝不要发送。**
