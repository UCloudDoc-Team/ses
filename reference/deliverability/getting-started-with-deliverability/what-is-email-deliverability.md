# 什么是邮件送达率？

邮件送达率（Email Deliverability）指邮件在规模化发送场景下，稳定进入收件箱（Inbox）的能力。  
从运营角度看，送达率关注的是收件箱落点质量，而不仅是收件服务器是否接受了邮件。

---

## 送达率与投递成功率的区别

投递成功率与送达率相关，但并不等价。

### 投递成功率（Delivery Rate）

```
投递成功率 = 成功投递到收件服务器的邮件数 / 发送总数
```

投递成功率同时包含进入收件箱和进入垃圾箱的邮件。

### 邮件送达率（Deliverability）

```
送达率 = 落入收件箱的邮件数 / 发送总数
```

送达率只关注进入收件箱的邮件，不包含垃圾箱和退信。

---

## 邮件投递路径

一封邮件通常会经历以下路径：

```
发件方 → ISP 接收 → 信誉评估 → 分类（收件箱/垃圾箱）→ 用户查看
```

邮箱服务商会基于发信信誉、认证状态、历史行为和用户互动信号，决定邮件最终落点。

---

## 影响送达率的核心因素

### 域名信誉（Domain Reputation）

域名信誉反映发信域名的长期可信度，通常受投诉率、退信率、认证质量和流量稳定性影响。

---

### IP 信誉（IP Reputation）

IP 信誉来源于发信 IP 的历史行为，包括黑名单状态、流量异常和垃圾邮件风险信号。

---

### 用户互动（User Engagement）

服务商会持续评估打开、点击、未读删除、投诉等互动信号，作为落点判定的重要依据。

---

### 内容质量（Content Quality）

内容质量包括语义相关性、HTML 结构规范、链接安全性，以及主题和发件身份的一致性。

---

### 发信策略（Sending Strategy）

循序渐进的发信节奏、稳定的发送频率和合理的用户分群，通常有助于提升送达率。

---

## 常见投递结果

| 状态 | 说明 |
| :--- | :--- |
| Inbox | 进入收件箱 |
| Spam | 已投递但被过滤到垃圾箱 |
| Bounce | 被收件方拒收，未成功投递 |

---

## 为什么送达率重要

1. 它是所有转化的“零到一”
无论营销内容写得多么动人，或者产品通知多么紧急，**“进收件箱”**永远是第一步。

触达即价值： 进不去收件箱，打开率、点击率和转化率都无从谈起。送达率每提升 1%，意味着你的营销成本（ROI）在底层逻辑上得到了即时优化。

避免资源浪费： 频繁的退信（Bounce）或被拦截，不仅是发信额度的浪费，更是对业务机会的错失。

2. 发信声誉的积累与反噬
邮件发送不是“一锤子买卖”，它具有极强的积累效应。

信誉资产： 当你持续保持高送达率，ISP（如 Gmail, Outlook）会认为你的域名和 IP 是可靠的，从而给予更高的发信权重。

黑名单风险： 反之，如果送达率低下且投诉率高，你的 IP 很快会被拉入黑名单。一旦声誉受损，修复成本极高，甚至可能导致整个企业的办公邮件或业务通知彻底瘫痪。

3. 关键业务的“确定性”
对于 SaaS 产品或电商平台，送达率往往关乎用户体验的生死线。

交易类邮件： 验证码、重置密码、支付确认等邮件必须“秒到”。如果送达率不稳定导致延迟或进入垃圾箱，用户会直接流失并对产品产生不信任感。

## 如何提升送达率

### 1）认证与基础设施

- 正确配置 SPF、DKIM、DMARC
- 使用独立发信域名
- 保持发信基础设施稳定且可信

---

### 2）发信策略

- 新域名和新 IP 进行渐进预热
- 避免短时间内的流量突增
- 保持发送节奏可预测

---

### 3）收件人列表质量

- 优先使用已确认订阅用户
- 定期清理无效与长期不活跃地址
- 避免购买或抓取来源不明的邮箱列表

---

### 4）内容与互动优化

- 内容与用户预期保持一致
- 发件人身份、主题和正文语义一致
- 持续提升正向互动并降低投诉率

---

## 监控指标建议

建议持续跟踪以下指标：

- 投递成功率（Delivery Rate）
- 收件箱到达率（Inbox Placement Rate，如可获取）
- 打开率（Open Rate）
- 点击率（Click Rate）
- 投诉率（Spam Complaint Rate）
- 退信率（Bounce Rate）

建议以趋势分析为主，而非单日数值判断；在条件允许时按邮箱服务商维度拆分分析。
