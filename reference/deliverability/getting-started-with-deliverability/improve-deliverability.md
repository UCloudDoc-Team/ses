# 邮件送达率提升指南

## 一、送达率的核心认知

邮件送达率并不等同于“邮件是否发送成功”。

从邮箱服务商的视角来看，真正关键的是：

> **是否信任该发件人，并愿意将邮件投递至收件箱**

主流邮箱服务商（如 Gmail、Outlook、Yahoo）都会基于发件人的历史行为，动态评估其可信度，并据此决定邮件的最终投递位置（收件箱 / 垃圾箱 / 拒收）。

因此，送达率问题本质上是一个“信任管理问题”，而不仅仅是技术问题。

---

## 二、影响送达率的核心要素

### 1. 发件人信誉（Sender Reputation）

发件人信誉是影响送达率的基础，由域名和 IP 两部分构成。

#### 域名信誉（Domain Reputation）

建议：

* 使用独立的发信子域名（如 `mail.yourdomain.com`）
* 区分事务邮件与营销邮件（不同域名发送）
* 保持域名长期稳定使用，避免频繁更换

域名是长期信誉的核心载体，一旦受损，恢复周期较长。

---

#### IP 信誉（IP Reputation）

建议：

* 使用历史干净的 IP 地址
* 避免受污染的共享 IP 池
* 控制发送节奏，避免短时间内流量激增

IP 更偏向“短期行为信誉”，对发送节奏变化较为敏感。

---

### 2. 邮件认证机制（基础必备）

完整的邮件认证是建立信任的前提，建议至少配置：

* **SPF**：声明允许发信的服务器
* **DKIM**：对邮件内容进行签名，确保完整性
* **DMARC**：定义认证策略并提供报告机制

基础配置原则：

> **SPF + DKIM + DMARC = 标准必备组合**

缺失或配置错误，都会显著降低送达成功率。

---

### 3. 发送预热（Warm-up）

在以下场景中必须进行预热：

* 新启用的域名或 IP
* 长时间未发送后重新启用

建议策略：

* 从小规模发送开始（如 50–100 封/天）
* 每日逐步增加发送量（20%–50%）
* 优先发送给活跃用户
* 保持稳定、连续的发送节奏

预热的核心目标，是让邮箱服务商逐步建立信任，而不是触发风控机制。

---

### 4. 邮件列表质量（List Quality）

列表质量直接决定用户反馈质量，是影响送达率的关键因素之一。

建议做法：

* 仅向已明确订阅的用户发送邮件
* 定期清理无效地址与退信地址
* 过滤长期无互动用户

应避免的行为：

* 购买或租用邮箱列表
* 抓取未经授权的数据
* 长期不维护发送列表

高质量列表通常意味着更低的投诉率和更高的互动率。

---

### 5. 内容与发送策略

#### 内容规范

* 避免明显的垃圾邮件特征（夸张营销词、诱导性表达）
* 保持 HTML 结构规范、兼容主流邮箱客户端
* 控制图片与文本比例
* 提供清晰可用的退订入口

#### 发送策略

* 控制发送频率，避免集中爆发式群发
* 按邮箱服务商进行分批发送（如 Gmail / Outlook 分开控制）
* 保持发送节奏稳定，避免大幅波动

内容与策略共同影响用户行为反馈，从而间接影响送达率。

---

## 三、关键指标参考范围

在日常运营中，可以通过以下指标评估整体健康状况：

| 指标                   | 建议范围        |
| -------------------- | ----------- |
| 投递成功率（Delivery Rate） | ≥ 90%       |
| 收件箱到达率（Inbox Rate）   | ≥ 70%       |
| 打开率（Open Rate）       | ≥ 10%（营销场景） |
| 投诉率（Complaint Rate）  | < 0.1%      |
| 退信率（Bounce Rate）     | < 2%        |

当某一指标持续异常时，应优先排查对应环节。

---

## 四、进阶优化策略

### 1. 域名隔离

建议对不同类型邮件使用独立子域名，例如：

* 事务邮件：`mail.yourdomain.com`
* 营销邮件：`marketing.yourdomain.com`

这样可以避免营销类邮件的负面反馈影响关键通知类邮件。

---

### 2. 域名对齐（Alignment）

确保发信域名与追踪域名保持一致，例如：

* 发信域名：`mail.yourdomain.com`
* 链接追踪域名：`track.yourdomain.com`

良好的对齐策略有助于通过 DMARC 校验，提高信任度。

---

### 3. 按邮箱服务商差异化优化

不同服务商关注点存在差异：

* Gmail：更关注用户互动（打开、点击）
* Outlook：对投诉更敏感
* Yahoo：更关注发送频率与稳定性

在发送策略上可以针对不同服务商进行精细化调整。

---

### 4. 基于用户行为的发送策略

建议优先发送给高活跃用户：

* 最近有打开行为的用户
* 最近有点击行为的用户

同时逐步减少对低活跃或无互动用户的发送。

这种方式可以显著提升整体互动率，并改善发件人信誉。

---

## 五、常见问题与排查方向

当送达率下降时，通常可以从以下几个方面排查：

### 1. 技术配置问题

* SPF / DKIM / DMARC 缺失或配置错误
* DNS 解析异常

---

### 2. 发信行为异常

* 短时间内发送量激增
* 发送节奏不稳定

---

### 3. 列表质量问题

* 投诉率升高
* 无效地址过多导致退信率上升

---

### 4. 内容质量问题

* 文案或设计被识别为营销垃圾内容
* 链接异常或指向低信誉域名
