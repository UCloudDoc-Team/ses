# 营销邮件定价

## 概述

uSpeedo 邮件发送服务采用「按月阶梯递进计费 + 价格档位延续」模型，具体如下：

-   计费依据为每月邮件发送量
-   费用按预设阶梯区间递进计算
-   每个新账期会继承上一个月达到的价格档位

## 邮件发送价格阶梯

以下价格均按每发送 1,000 封邮件（USD）计算；单封邮件扣费 = 对应档位单价 / 1,000。

| 月发送量区间 | 每 1,000 封单价（USD） |
| --- | --- |
| 前 100,000 封 | $0.35 |
| 100,001 – 500,000     | $0.32                               |
| 500,001 – 1000,000    | $0.30                               |
| 1,000,001 – 2,000,000 | $0.27                               |
| 2,000,001 – 5,000,000 | $0.24                               |
| > 5,000,000 | 联系销售获取更优价格 |

## 计费模型

### 递进（阶梯）计费

同一账期内的邮件用量按递进阶梯计费，即每一段用量都按其所在档位单独计算。

-   随着发送量增加，价格档位按顺序生效
-   每一段用量独立按对应档位单价计费
-   已计费用量不会因后续升档而追溯重算

### 计费周期

-   按自然月（UTC）计费
-   用量实时累积
-   每个账期结束时完成费用结算

## 价格档位延续机制（Tier Carry-Over）

从第二个账期起，价格会**继承上个月达到的档位**，该档位称为**起始档位（Starting Tier）**。

### 规则

-   本月起始档位由上一个自然月总发送量决定
-   在新账期中：
    -   所有**不超过起始档位上限**的用量，按该起始档位单价计费
    -   超出该上限后，继续按更高档位递进计费

### 📒 示例

若某客户在第 1 个月发送 **1,200,000 封邮件**，则其所在档位为：

→ 档位：**1,000,000 – 1,999,999（$0.27）**

#### 第 2 个月计费：

-   前 1,999,999 封 → 按 **$0.27** 计费
-   2,000,000 – 4,999,999 → 按 **$0.24** 计费
-   ≥ 5,000,000 → 按更低价格计费

👉 更早的低档位（如 $0.35 / $0.32 / $0.30）会被**跳过**，从而确保客户直接享受更优单价。

### 首月例外

-   若为首个账期、无上月账期数据，则所有客户均从**基础档位（最低发送量档位）**开始
-   从首封邮件起按标准递进规则计费

## 支付说明

### 仅支持预付费

-   服务仅采用预付费计费模式
-   用量费用会从可用余额 / Credits 中实时扣减

支持的支付方式与充值说明，请参考 **Accepted Payment Billing**。

### 退款政策

-   除非另有说明，所有费用一经扣除不予退还
-   如有赠送营销额度（Promotional Credits），不可提现、不可转让

## 企业版与定制报价

适用于高发送量或发送量可预测的客户：

-   支持签订定制价格协议
-   在承诺发送量前提下，可能获得：
    -   更低固定单价
    -   SLA 服务保障
    -   专属基础设施选项

如需企业方案，请联系销售团队。

## 可计费事件

### 计费范围内

以下情况会被计费：

-   发送请求被系统成功接受（accepted for processing）

一旦请求被接受：

-   无论最终投递结果如何，均会计费，包括：
    -   Sent
    -   Delivered
    -   Bounced
    -   Blocked
    -   Temporary Issued

### 不计费范围

以下情况**不计费**：

-   因**系统侧错误或服务故障**导致发送失败的邮件
-   在被系统接受前即被拒绝的请求（例如无效 API 请求）
