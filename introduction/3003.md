# 产品功能

## 发信配置

- 发信域名验证：通过 DNS 记录证明域名所有权，并配置邮件身份验证。
- 发信地址管理：在已验证域名下创建发件人地址和显示名称。
- 模板管理：维护主题及正文，支持复用统一的邮件内容。
- 追踪域名：通过独立域名记录邮件打开、链接点击等行为。

## 邮件发送

- 普通发送：适合测试或少量收件人。
- 批量发送：面向已获得授权的收件人列表执行批量任务。
- 发送速率：按业务需要控制邮件释放速度，支持新域名逐步放量。
- 程序化接入：业务系统可按已开放的 API 或 SMTP 方式发送。

## 追踪与分析

- 查看请求量、成功量、失败量等统计指标。
- 查询单封邮件的投递状态及失败原因。
- 通过回调接收异步投递事件，用于业务侧状态同步。

域名认证、追踪域名和发送速率的详细说明，请参考[控制台指南](/ses/guide/config/7001)。
