# 概览

邮件推送服务（SES）是一项面向事务通知、验证码、营销活动等场景的云端邮件发送服务。您可以通过控制台、API 或 SMTP 接入，在完成发信域名验证、发信地址和模板配置后向用户发送邮件，并在控制台查看发送统计与投递结果。

## 使用流程

1. 添加发信域名，并按页面提示配置 DNS 验证记录，等待解析生效。
2. 创建发信地址和邮件模板，等待审核或状态生效。
3. 选择控制台、API 或 SMTP 方式发送测试邮件。
4. 小流量开始发送，依据退信、投诉和送达数据逐步调整发信量。
5. 配置回调地址并持续关注投递结果。
