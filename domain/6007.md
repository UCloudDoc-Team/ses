# 追踪域名

追踪域名用于统计邮件打开、链接点击、退订等行为事件。配置自定义追踪域名后，邮件中的追踪链接可以使用您的品牌域名或同根子域名，便于统一信誉和用户识别。

## 工作方式

以点击追踪为例，邮件中的原始链接会被替换为追踪链接。收件人点击后，请求先到达追踪域名，系统记录点击事件后再跳转到原始目标地址。

打开追踪通常依赖邮件中的追踪像素。由于部分邮箱客户端会禁用图片加载、缓存图片或代理请求，打开数据只能作为趋势参考，不应作为唯一判断依据。

## 域名建议

建议使用独立子域名作为追踪域名，例如：

| 用途 | 示例 |
| --- | --- |
| 发信域名 | `mail.example.com` |
| 追踪域名 | `track.example.com` |

追踪域名和发信域名尽量使用同一个根域名，有助于保持品牌一致性，也便于投递信誉治理。

## 配置步骤

1. 在控制台打开追踪域名或相关配置页面。
2. 添加用于追踪的子域名，例如 `track.example.com`。
3. 复制控制台生成的 CNAME 记录。
4. 前往 DNS 服务商处添加记录。
5. 等待解析生效后，返回控制台完成验证。
6. 发送测试邮件，检查打开、点击和跳转是否正常。

## 使用建议

- 不要直接使用网站根域名作为追踪域名。
- 不要频繁更换追踪域名，以免影响数据连续性和域名信誉。
- 生产环境和测试环境可使用不同追踪子域名。
- 确认追踪域名支持 HTTPS，避免浏览器或邮箱客户端提示风险。
- 链接跳转目标应真实、可访问，避免使用短链或多层跳转。

## 常见问题

### 点击后跳转缓慢怎么办？

请先检查 DNS 是否完全生效、目标页面是否可访问、是否存在多层重定向。若只在部分地区或服务商异常，可结合发送记录和访问日志进一步排查。

### 为什么打开率不准确？

打开率受图片加载策略、客户端缓存、代理服务和用户隐私设置影响。建议结合点击率、退订率、投诉率和转化数据一起分析。

### 可以和发信域名使用同一个域名吗？

建议使用不同子域名承载不同用途，例如 `mail.example.com` 发信，`track.example.com` 追踪。这样更便于管理，也能降低互相影响。
