# 域名认证

域名认证用于验证域名所有权，并配置邮件身份认证记录。完成认证后，您可以在该域名下创建发信地址，并通过控制台、API 或 SMTP 发送邮件。

## 准备工作

开始前请确认：

- 已拥有可用于发信的域名或子域名。
- 可登录该域名的 DNS 服务商后台。
- 已进入 UCloud 邮件推送服务控制台。
- 已规划邮件类型和发信用途，例如事务通知或营销触达。

## 配置步骤

1. 进入邮件推送SES服务控制台，打开邮件配置-发信域名管理页面（[点击此处前往](https://console.ucloud.cn/ses/email-config)），点击添加域名。
![img](https://uc-ses-docs.cn-sh2.ufileos.com/%E6%B7%BB%E5%8A%A0%E5%9F%9F%E5%90%8D1.png)
2. 添加您拥有管理权限的域名或子域名。
![img](https://uc-ses-docs.cn-sh2.ufileos.com/%E6%B7%BB%E5%8A%A0%E5%9F%9F%E5%90%8D2.png)
3. 选择该发信域名所属类型（营销型域名：适用于营销活动、新闻通讯、促销广告等批量邮件。事务性域名：用于系统触发的即时邮件，如验证码、账单、告警和通知。）
![img](https://uc-ses-docs.cn-sh2.ufileos.com/%E6%B7%BB%E5%8A%A0%E5%9F%9F%E5%90%8D3.png)
4. 点击被添加域名的“验证”操作，根据页面提示获取 DNS 记录，包括记录类型、主机记录和值。
![img](https://uc-ses-docs.cn-sh2.ufileos.com/%E6%B7%BB%E5%8A%A0%E5%9F%9F%E5%90%8D4-1.png)
![img](https://uc-ses-docs.cn-sh2.ufileos.com/%E6%B7%BB%E5%8A%A0%E5%9F%9F%E5%90%8D4-2.png)
5. 登录 DNS 服务商后台，逐条添加控制台提供的记录。
6. 等待 DNS 解析生效。
7. 返回控制台发起验证，查看认证结果。

不同 DNS 服务商对“主机记录”“名称”“Host”“Name”的展示方式不同，但应以控制台给出的记录类型和值为准。

## 生效时间

DNS 解析通常需要数分钟到数小时生效，少数情况下可能受服务商缓存、TTL、递归解析缓存影响而延迟。修改记录后请耐心等待，再重新发起验证。

## 状态说明

| 状态 | 说明 |
| --- | --- |
| 待验证 | 域名已添加，等待 DNS 记录配置或解析生效 |
| 验证失败 | 至少一项记录未通过校验，需要核对记录类型、主机记录和值 |
| 已验证 | 域名记录校验通过，可继续创建发信地址 |
| 异常 | DNS 记录被删除或变更，可能影响发送或投递表现 |

## 注意事项

- 请完整复制控制台提供的记录值，不要自行删减、换行或替换字符。
- 若同一主机记录已有同类型记录，请确认是否允许并存，避免互相覆盖。
- 若使用子域名发信，请注意主机记录是否需要带子域名前缀。
- 不建议在生产发送期间删除 SPF、DKIM、DMARC 等认证记录。
- 域名认证通过不代表邮件一定进入收件箱，最终落点还会受到信誉、内容、名单质量和用户反馈影响。

如需了解各类记录的作用，请参考[DNS 记录说明](/ses/domain/6005)。
