# 邮件送达率概述

邮件送达率关注邮件能否稳定进入收件人的收件箱，而不仅是发送请求是否被服务接受。邮件推送服务可以提供发送、投递、统计和回调能力，但最终落点还会受到收件服务商策略、发信信誉、内容质量和用户反馈影响。

## 投递成功与送达率

投递成功通常表示收件服务器已接受邮件；送达率更关注邮件是否进入收件箱。邮件即使被对方服务器接收，也可能进入垃圾箱、推广分类或被用户规则移动。

| 概念 | 说明 |
| --- | --- |
| 请求成功 | 服务已接受发送请求 |
| 投递成功 | 收件服务器确认接收 |
| 进入收件箱 | 邮件最终出现在用户主要收件位置 |
| 退信 | 收件方拒收或地址不可达 |

排查投递问题时，应结合发送记录、投递回应、Webhook 事件和用户侧反馈综合判断。

## 影响因素

影响送达率的常见因素包括：

- 域名和 IP 的历史信誉。
- SPF、DKIM、DMARC 等认证是否完整且有效。
- 新域名是否经过合理预热。
- 收件人是否明确授权并保持活跃。
- 退信率、投诉率、退订率是否异常。
- 邮件主题、正文、链接和 HTML 结构是否可信。
- 发送量和发送节奏是否稳定。

## 监控指标

建议持续关注以下指标：

- 请求量和接受量。
- 投递成功量和失败量。
- 退信、拦截、临时失败。
- 打开、点击、退订和投诉。
- 不同发信域名、收件服务商、任务之间的趋势变化。

单日数据可能受活动规模、收件人结构和服务商策略影响，建议以趋势为主，不要只凭单个指标判断整体质量。

## 基本治理思路

1. 完成域名认证并保持 DNS 记录有效。
2. 使用专用子域名区分事务邮件和营销邮件。
3. 新域名从小流量开始发送，逐步放量。
4. 仅向合法、明确授权的收件人发送邮件。
5. 及时停止向退订、投诉、硬退信地址发送。
6. 关注统计和回调数据，异常时先降速再排查。
