# 发件人合规要求

主流邮箱服务商会持续收紧对发件人的认证、授权、退订和投诉率要求。使用邮件推送服务发送邮件时，发送方应确保自身业务流程、收件人来源和邮件内容符合适用法律法规及收件服务商规则。

本文为通用使用建议，不构成法律意见。涉及具体合规义务时，请结合业务所在地、收件人所在地和公司合规要求评估。

## 基础要求

| 方向 | 建议 |
| --- | --- |
| 邮件认证 | 完成 SPF、DKIM、DMARC 等认证配置 |
| 用户授权 | 仅向明确授权或业务合理预期内的收件人发送 |
| 退订机制 | 营销邮件提供清晰、可用的退订方式 |
| 内容规范 | 不使用误导、冒充、欺诈或隐藏真实意图的内容 |
| 投诉控制 | 持续监控投诉并及时停止向投诉地址发送 |
| 名单治理 | 清理无效、退订、投诉和长期无互动地址 |

## 邮件认证

建议完整配置 SPF、DKIM 和 DMARC，并确保发件身份与认证域名保持一致。认证缺失或失败会降低邮件可信度，也可能导致拒收或垃圾箱过滤。

## 用户授权

营销邮件应基于明确订阅、授权或其他合法合规依据发送。禁止使用购买、抓取、撞库或未经授权导入的地址列表。

收集邮箱地址时，建议明确告知用途、发送类型和退订方式。

## 退订机制

营销邮件应提供清晰可见、可正常访问的退订入口。退订流程不应设置不必要障碍。收到退订后，应及时停止继续发送营销内容。

如业务系统支持标准退订头，可按自身系统能力配置 `List-Unsubscribe` 等头部，提升邮箱客户端识别能力。

## 投诉率控制

投诉率过高会影响发信信誉，严重时可能触发收件服务商限流、拒收或平台侧风控。建议将投诉率作为重点监控指标，并在异常时降低发送频率、清理名单和复查内容。

## 内容规范

- 发件人名称应真实、稳定，不冒充他人或品牌。
- 主题应准确表达邮件目的，不夸大或诱导点击。
- 正文应说明邮件来源，避免隐藏商业意图。
- 链接应指向可信域名，避免短链和多层跳转。
- 不发送钓鱼、恶意软件、违法违规或侵犯他人权益的内容。

## 长期维护

合规不是一次性配置。建议定期复盘授权来源、退订处理、投诉处理、模板内容和发送频率，确保发送行为与用户预期一致。
