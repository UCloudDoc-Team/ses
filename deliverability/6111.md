# 域名信誉与发送额度

发信域名的信誉会受到发送历史、认证质量、退信率、投诉率、收件人互动和发送稳定性等因素影响。域名信誉越稳定，越有利于持续、可控地扩大邮件发送规模。

具体发送额度、速率限制和风控规则可能因账户状态、产品策略和控制台配置而不同，请以控制台当前展示为准。

## 影响域名信誉的因素

- 域名是否完成认证并保持 DNS 记录有效。
- 是否使用稳定、连续的发送节奏。
- 退信、投诉、退订和拦截是否异常。
- 收件人是否来自合法、明确授权的业务场景。
- 邮件内容是否与用户预期一致。
- 是否及时停止向高风险地址继续发送。

## 发送额度

发送额度用于控制一定时间内可发送的邮件量。额度可能与账户状态、域名状态、历史发送表现和平台策略相关。

使用建议：

- 新域名按控制台额度和预热节奏逐步发送。
- 不要为了快速放量频繁更换域名。
- 当额度不足或发送受限时，先检查失败原因、退信率、投诉率和账户状态。
- 大规模发送前预留测试、审核和排查时间。

## 降速与暂停

当系统检测到异常发送、退信或投诉明显升高、域名认证异常、内容风险或账户风险时，可能出现发送受限、降速或暂停发送。

出现限制时，建议：

1. 暂停新增批量任务。
2. 查看控制台提示、发送记录和投递回应。
3. 核对域名认证和发送速率配置。
4. 清理退订、投诉、硬退信和无效地址。
5. 复查近期发送内容和收件人来源。
6. 逐步恢复发送，不要立即回到原有峰值。

## 信誉恢复

信誉恢复通常需要持续稳定的正向发送表现。短期内反复放量、降速、再放量，可能延长恢复周期。

建议恢复阶段优先发送给活跃、明确授权的用户，并持续观察不同收件服务商的投递结果。

## 与数据统计的关系

域名信誉治理应结合数据统计和投递回应一起进行。不要只看请求成功量，也要关注失败原因、投诉、退订、打开和点击等趋势。

相关数据可在[数据统计](/ses/guide/7201)和[投递回应](/ses/guide/7203)中查看。
