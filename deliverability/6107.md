# 降低垃圾邮件风险

邮件进入垃圾箱通常不是单一原因造成的，而是由发信身份、历史信誉、发送行为、内容质量和用户反馈共同影响。发送方应从配置、名单、内容和节奏四个方面持续治理。

## 常见原因

### 域名信誉不足

新域名、长期未使用域名、历史投诉偏高或发送节奏异常，都可能降低收件服务商对发件方的信任。

### 认证缺失或异常

SPF、DKIM、DMARC 配置缺失、失效或未对齐，可能导致邮件被识别为伪造或可疑来源。

### 用户反馈差

投诉、退订、未读删除和长期无互动都会影响后续邮件表现。投诉率升高时，应立即降低发送量并排查名单来源和内容预期。

### 名单质量差

大量无效地址、长期不活跃地址、购买或抓取来源的邮箱列表，会提高退信和投诉风险。

### 内容风险

夸张或误导性主题、过多外链、短链、多层跳转、纯图片邮件、异常 HTML 结构、缺少退订说明，都可能触发过滤。

## 降低风险的做法

- 完成并保持域名认证记录有效。
- 使用专用子域名区分事务邮件和营销邮件。
- 只向合法、明确授权的收件人发送。
- 定期移除退订、投诉、硬退信和长期无互动地址。
- 控制发送频率，避免短时间流量突增。
- 使用清晰、准确、与正文一致的主题。
- 避免使用短链或不可信跳转域名。
- 营销邮件提供清晰可用的退订入口。
- 在大批量发送前先小范围测试。

## 投诉率治理

用户将邮件标记为垃圾邮件时，会产生强负面信号。为降低投诉率：

1. 明确说明邮件来源和发送原因。
2. 控制发送频率，避免过度触达。
3. 让退订比投诉更容易。
4. 对长期无互动用户降频或停止发送。
5. 收到投诉后立即停止向该地址发送。

## 排查路径

当垃圾箱反馈或拦截明显增加时，建议按以下顺序排查：

1. 检查域名认证和追踪域名配置。
2. 查看是否近期突然放量。
3. 按收件服务商拆分投递数据。
4. 检查邮件主题、链接、HTML 和图片比例。
5. 抽样核对收件人来源和活跃度。
6. 降低发送速率并观察指标是否恢复。
