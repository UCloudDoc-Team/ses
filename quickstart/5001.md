# 邮件配置

## 1. 添加发信域名

进入邮件推送服务控制台，打开“发信域名”，添加您拥有管理权限的域名或子域名。建议为邮件发送单独使用子域名，以便隔离发信信誉。

## 2. 配置 DNS

按控制台给出的记录类型、主机记录和值，在域名 DNS 服务商处添加记录。DNS 生效需要一定时间；生效后返回控制台发起验证。

## 3. 创建发信地址

在已验证域名下创建发信地址，设置易于识别的显示名称。发件人名称应与业务或品牌一致，避免误导收件人。

## 4. 创建模板

填写邮件主题与正文。提交前检查变量、图片、跳转链接、退订说明和移动端显示效果，并按页面要求完成审核。

完成以上配置后，可继续[发送第一封邮件](/ses/quickstart/5003)。
