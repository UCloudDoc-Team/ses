# 邮件配置

本文介绍完成首次发送前需要准备的基础配置。域名认证、DNS 记录和送达率治理的详细说明，请参考[域名与认证](/ses/domain/6001)和[送达率与信誉](/ses/deliverability/6101)。

## 1. 添加发信域名

进入邮件推送服务控制台，打开“发信域名”，添加您拥有管理权限的域名或子域名。正式发送建议使用专用子域名，例如 `mail.example.com` 或 `notify.example.com`，以便隔离发信信誉。

## 2. 配置 DNS

按控制台给出的记录类型、主机记录和值，在域名 DNS 服务商处添加记录。DNS 生效需要一定时间；生效后返回控制台发起验证。

配置时请完整复制记录值，不要自行替换为历史平台或其他服务商的记录。若验证失败，可参考[域名认证常见问题](/ses/domain/6011)排查。

## 3. 创建发信地址

在已验证域名下创建发信地址，设置易于识别的显示名称。发件人名称应与业务或品牌一致，避免误导收件人。

## 4. 创建模板

填写邮件主题与正文。提交前检查变量、图片、跳转链接、退订说明和移动端显示效果，并按页面要求完成审核。

## 5. 发送测试邮件

首次发送前，请先向您可控制的邮箱发送测试邮件，检查主题、正文、变量、链接、图片和字符编码是否正常。若面向不同收件服务商发送，建议分别使用测试邮箱验证收件箱、垃圾箱和推广分类中的显示情况。

完成以上配置后，可继续[发送第一封邮件](/ses/quickstart/5003)。
