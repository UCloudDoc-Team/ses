# 邮件配置

本文介绍从域名准备到发送测试的完整配置路径。首次使用建议按本文顺序完成配置，再进入[邮件发送](/ses/quickstart/5003)。

域名认证、DNS 记录和追踪域名的详细说明位于[控制台指南 > 邮件配置](/ses/guide/config/7001)下；送达率治理相关内容位于[控制台指南 > 送达率与信誉](/ses/deliverability/6101)下。

## 开始前准备

请先确认：

- 已有一个可以管理 DNS 记录的域名或子域名。
- 可以登录该域名当前使用的 DNS 服务商。
- 已明确邮件用途，是事务通知、验证码、系统告警，还是营销邮件。
- 已准备好一个自己可以控制的测试邮箱。
- 如使用 API 或 SMTP，已了解凭证应保存在服务端，不应写入前端代码或公开仓库。

## 1. 添加发信域名

进入邮件推送服务控制台，打开“邮件配置 > 发信域名”，添加您拥有管理权限的域名或子域名。

正式发送建议使用专用子域名，例如 `mail.example.com`、`notify.example.com` 或 `marketing.example.com`，而不是直接使用网站主域名。事务邮件和营销邮件建议使用不同的子域名，以便分别管理发信信誉。

关于主域名、子域名和邮件类型的选择，请参考[发信域名概述](/ses/domain/6001)和[事务邮件与营销邮件](/ses/deliverability/6103)。

## 2. 配置 DNS 并完成认证

在域名详情中打开验证操作，获取控制台生成的 DNS 记录。按记录类型、主机记录和值，在当前生效的 DNS 服务商处逐条添加。

DNS 记录可能包括 SPF、DKIM、DMARC、MX 或其他控制台要求的记录。记录的具体内容必须以当前控制台展示为准，不要照搬历史平台或其他服务商的记录。

DNS 生效需要一定时间。记录完成配置后，返回控制台发起验证；如果暂时失败，请等待解析缓存刷新后再次尝试。

配置时请完整复制记录值，不要自行替换为历史平台或其他服务商的记录。若验证失败，可参考[域名认证常见问题](/ses/domain/6011)排查。

完整的控制台操作和截图请参考[域名认证](/ses/domain/6003)；各类 DNS 记录的作用请参考[DNS 记录说明](/ses/domain/6005)。

## 3. 创建发信地址

在已验证域名下创建发信地址，并设置易于识别的显示名称。

建议：

- 发件人名称与品牌或业务主体保持一致。
- 使用能表达用途的地址，例如 `notice@example.com`、`security@example.com` 或 `billing@example.com`。
- 事务邮件和营销邮件使用不同发信地址，便于管理用户预期和退订。
- 如需接收用户回复，确认回复地址真实可用。

更多说明请参考[发信地址](/ses/guide/config/7003)。

## 4. 准备邮件内容

根据控制台当前支持的方式填写或选择邮件主题和正文。发送前检查以下内容：

- 主题是否准确表达邮件目的。
- 变量是否与收件人数据字段正确对应。
- 变量缺失时是否有合理的默认值或业务兜底。
- 图片、链接和跳转域名是否可信且可以正常访问。
- 营销邮件是否包含清晰的退订入口或退订说明。
- 正文在常用邮箱客户端和移动端是否显示正常。

模板字段和安全注意事项请参考[邮件模板](/ses/guide/config/7005)。

## 5. 发送测试邮件

首次发送前，请先向您可控制的测试邮箱发送邮件，检查：

- SMTP 或 API 凭证是否配置正确。
- 发件人地址是否与已验证域名一致。
- 主题、正文、变量和字符编码是否正确。
- 图片、链接和追踪跳转是否正常。
- 邮件是否进入收件箱、垃圾箱或推广分类。
- 发送记录中是否产生对应的请求和投递状态。

普通发送的操作步骤请参考[普通发送](/ses/guide/send/7101)；如果要发送给收件人列表，请先阅读[收件人列表](/ses/guide/send/7103)。

## 6. 进入正式发送

测试确认无误后，再根据业务类型选择：

- 少量通知或单封测试：使用[普通发送](/ses/guide/send/7101)。
- 已授权的收件人列表：使用[批量发送](/ses/guide/send/7105)。
- 需要平滑释放邮件：配置[发送速率](/ses/guide/send/7107)。
- 需要接收异步状态：配置[回调地址](/ses/guide/config/7007)，并参考[Webhook 文档](/ses/webhook/8201)。

新域名或长期未使用的域名应先小流量发送，再根据退信、投诉、临时失败和互动数据逐步放量。具体建议请参考[域名预热](/ses/deliverability/6105)。

完成以上配置后，可继续[邮件发送](/ses/quickstart/5003)。
