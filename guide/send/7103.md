# 收件人列表

收件人列表用于管理批量任务的目标地址。导入前请确认每个地址均来自明确授权的业务场景。

- 使用控制台支持的文件格式和字符编码。
- 按模板要求提供邮箱及变量字段，列名和字段数量保持一致。
- 去除重复、空值和格式错误的地址。
- 排除退订、硬退信、投诉和内部抑制名单中的地址。

含个人信息的列表应限制访问权限并设置合理的保存期限。不要将真实用户列表上传到测试环境或公开仓库。

批量发送前，请结合[批量发送](/ses/guide/send/7105)检查任务配置，并参考[发件人合规要求](/ses/deliverability/6109)确认收件人来源和退订处理符合要求。
