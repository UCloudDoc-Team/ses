# 发信域名

发信域名是邮件身份和信誉的基础。

## 添加与验证

1. 在控制台添加域名或专用子域名。
2. 复制控制台生成的 DNS 记录，前往 DNS 服务商完成配置。
3. 等待解析生效后，在控制台执行验证。
4. 验证通过后再创建发信地址。

若验证失败，请检查记录类型、主机记录和值是否完整复制，并确认没有被同名记录覆盖。修改 DNS 后应等待缓存刷新再重试。

删除或改变验证记录可能导致域名状态异常，进而影响发送。
