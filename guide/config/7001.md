# 发信域名管理

发信域名管理用于查看和维护邮件发送所使用的域名。域名认证的完整操作请参阅[域名认证](/ses/domain/6003)；本页仅说明域名认证完成后的日常管理关系。

## 管理范围

- 查看域名的认证状态和异常提示。
- 确认域名是否仍可用于创建发信地址和发送任务。
- 根据业务用途区分事务邮件域名和营销邮件域名。
- 在域名发生变更前评估对发送、追踪和投递的影响。

## 添加新域名

添加新域名时，请先阅读[发信域名概述](/ses/domain/6001)，再按照[域名认证](/ses/domain/6003)中的步骤完成 DNS 配置和验证。

## 认证后的检查

1. 确认域名状态为已验证或控制台显示的正常状态。
2. 确认认证记录仍然存在，未被 DNS 服务商删除或覆盖。
3. 在域名下创建发信地址，并检查显示名称和回复地址。
4. 发送测试邮件，确认投递记录和回调事件正常。

## 修改或停用域名前

删除或修改 SPF、DKIM、DMARC、MX 或追踪域名记录，可能导致认证失效、签名验证失败或行为追踪异常。停用域名前，请确认没有正在运行的发送任务或业务系统仍在使用该域名。

如需了解各类 DNS 记录，请参考[DNS 记录说明](/ses/domain/6005)；如需处理认证失败，请参考[域名认证常见问题](/ses/domain/6011)。
