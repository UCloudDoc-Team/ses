# 按量后付费

UC SES 按量后付费以提交成功的邮件数量为计费依据，价格为 **¥2 / 1,000 封**，使用后出账单。

## 价格与结算方式

| 项目 | 说明 |
| --- | --- |
| 计费项 | 邮件发送量 |
| 单价 | ¥2 / 1,000 封 |
| 计费口径 | 按提交成功的邮件数量计费 |
| 付费方式 | 后付费，出账单结算 |
| 内容审核 | 发送内容需要审核 |

## 计费范围

- **提交成功**：服务已接受发送请求，对应邮件纳入发送量统计。
- **提交失败**：服务未接受发送请求，不纳入提交成功的计费数量。
- **提交成功后投递失败或退信**：仍按提交成功口径统计，不因最终投递结果改变计费口径。
- **多个收件人**：按各收件人的提交结果分别统计，不按 API 请求次数或批量任务数量计费。
- **业务主动重新提交**：如果重发请求再次提交成功，按新的提交成功邮件统计。重试前应核对原请求状态，避免重复提交。

> 请求超时不一定表示提交失败。请结合请求结果、发送记录和回调事件确认状态，不要仅凭客户端超时判断是否计费。

## 费用计算

按量费用按未由免费额度或有效资源包抵扣的提交成功邮件数量核算。

```text
按量费用估算（元） = 按量计费邮件数量（封） ÷ 1,000 × 2
```

以下示例假设表中邮件全部提交成功，且全部进入按量计费范围，不涉及免费额度或资源包抵扣。

| 按量计费邮件数量 | 费用估算（元） |
| ---: | ---: |
| 1,000 封 | 2 |
| 10,000 封 | 20 |
| 50,000 封 | 100 |
| 100,000 封 | 200 |

例如，10,000 封邮件已提交成功，其中 500 封最终退信，按量费用仍按 10,000 封估算，为 **¥20**，而不是仅按最终投递成功的 9,500 封计算。

> ¥2 / 1,000 封是计费单价的展示单位。是否存在不足 1,000 封的取整规则、账单金额精度和最低计费金额，当前定价规则未明确；示例仅用于费用估算，不构成具体账单精度的承诺。

## 账单说明

按量后付费在使用后出账单。核对费用时，应区分提交成功数量、最终投递数量，以及免费额度和资源包抵扣数量，不应直接用最终投递成功量计算账单。

具体出账周期、出账时间、扣款时间、金额精度及欠费处理规则需进一步确认，本文不预设小时、日或月结算周期。
