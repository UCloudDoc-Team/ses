# 免费测试额度

UC SES 提供 **1,000 封免费测试额度**，用于在正式发信前验证服务配置与发送流程。

## 额度说明

| 项目 | 说明 |
| --- | --- |
| 免费测试额度 | 1,000 封 |
| 计量单位 | 封，按提交成功的邮件数量统计 |
| 内容审核 | 发送内容需要审核，免费测试不豁免审核 |
| 适用用途 | 验证发信配置、邮件内容、发送流程和投递效果 |

免费额度内的邮件不产生按量发送费用。提交成功后，即使邮件最终退信或投递失败，仍纳入提交成功的发送量；提交失败的邮件不计入该发送量。

## 测试前准备

1. 完成[发信域名](/ses/guide/config/7001)验证及[发信地址](/ses/guide/config/7003)配置。
2. 准备[邮件模板](/ses/guide/config/7005)，并按平台要求完成发送内容审核。
3. 使用您可控制的测试邮箱，检查主题、正文、变量、链接和排版。
4. 查看[投递回应](/ses/guide/7203)或 [Webhook 事件](/ses/webhook/8201)，确认实际投递结果。

## 免费额度之外的发送量

不由免费额度或有效资源包抵扣的提交成功邮件，按 **¥2 / 1,000 封**的价格核算按量费用。您也可以根据预计发送量选择有效期为 **1 年**的 SES 资源包。

详情请参见[按量后付费](/ses/guide/billing/7305)和 [SES 资源包](/ses/guide/billing/7307)。

## 注意事项

- 免费测试额度是发送数量额度，不代表每天可发送的数量或每秒发送速率。
- 新域名应从小流量开始测试，免费额度不能替代[发信信誉预热](/ses/quickstart/5005)。
- 免费额度的领取条件、账户归属、有效期、是否补充或重置、每日使用上限，以及与资源包的抵扣优先级，当前定价规则未明确，需进一步确认。请勿将 1,000 封理解为每天或每月赠送的额度。
