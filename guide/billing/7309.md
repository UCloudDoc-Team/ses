# 计费常见问题

## 提交成功是否等于投递成功？

不等于。提交成功表示 SES 已接受发送请求；投递成功表示邮件已送达收件方邮件系统。UC SES **按提交成功计费**，最终退信或投递失败不会改变已提交成功邮件的计费口径。

## 提交失败是否计费？

服务未接受的发送请求不纳入提交成功的计费数量。若仅发生客户端超时，不能据此认定提交失败，应先核对发送记录或回调结果，再决定是否重新提交。

## 批量发送是按任务数还是按邮件数计费？

按提交成功的邮件数量统计，不按批量任务数或接口调用次数统计。发送给多个收件人时，各收件人分别计为一封邮件；部分收件人提交失败时，只统计提交成功的部分。

## 免费测试额度是否每天或每月重新赠送？

当前明确的免费测试额度为 **1,000 封**。领取条件、归属账户、有效期、重置规则和每日使用上限尚未明确，不能理解为每天或每月赠送 1,000 封。

## 使用免费额度或购买资源包后，还需要内容审核吗？

需要。免费测试、按量后付费和资源包发送均需完成发送内容审核。购买资源包不代表免审核，也不会自动提升发信信誉或解除发送限制。

## 如何比较资源包与按量后付费的成本？

按量价格为 **¥2 / 1,000 封**，资源包有效期为 **1 年**。例如，同等 50,000 封邮件的按量费用为 ¥100，5 万封资源包价格为 ¥88；全部使用时价格差为 ¥12。

比较时应考虑一年内能否实际使用资源包额度。详细规格及费用对比请参见 [SES 资源包](/ses/guide/billing/7307)。

## 资源包用尽或到期后，是否自动转为按量后付费？

当前定价规则未明确自动转换机制，也未明确到期剩余额度的处理方式。请在购买和正式使用前确认相关规则；不要将“支持按量后付费”直接理解为“资源包用尽或到期后自动转换”。

## 账单什么时候出？欠费是否影响发送？

目前明确的是 **后付费出账单**。出账周期、出账时间、扣款方式，以及欠费后的发送限制和恢复条件需进一步确认，不能直接套用其他厂商的结算或停服规则。

## 资源包可以退款、延期或转给其他账户吗？

当前定价规则只明确资源包规格、价格及 1 年有效期，未明确退订、退款、延期、转移或共享政策。应在购买前确认，不应承诺支持或不支持。

## 待确认的计费细则

以下项目尚未在本次提供的 UC SES 定价规则中明确，应由产品或计费负责人确认后更新文档。

| 类别 | 待确认内容 |
| --- | --- |
| 免费测试额度 | 领取条件；账户归属；有效期；是否补充或重置；每日使用上限 |
| 抵扣范围与优先级 | 免费额度和资源包的抵扣顺序；主子账户、地域及发送方式的适用范围 |
| 资源包生效 | 生效时间；1 年有效期的起算点；多个资源包的有效期是否独立 |
| 多资源包扣减 | 是否支持叠加购买；多个资源包的扣减顺序 |
| 用尽与到期 | 是否自动转按量计费；到期剩余额度是否失效；是否支持结转或延期 |
| 退订与退款 | 未使用、部分使用及已到期资源包的退订或退款条件 |
| 续购与共享 | 续购流程；是否支持自动续购、转移或跨账户共享 |
| 账单与扣款 | 出账周期、出账时间、扣款时间；不足 1,000 封的计算方式；金额精度和最低计费金额 |
| 欠费处理 | 欠费后的发送限制；资源包是否仍可使用；恢复服务条件 |
| 购买流程 | 购买入口、支付步骤及如何核对资源包订单与有效期 |
